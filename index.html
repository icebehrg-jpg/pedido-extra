Automação de pedidos Kalunga

Extraia os dados das lojas, gere pedidos e prepare aprovações.
Etapa 1

Obter dados de estoque das lojas

Na tela do produto no sistema, copie e execute o script para montar uma planilha com estoque, máximo e diferença.

Como obter: abra a tela que mostra todas as lojas e as colunas de estoque e estoque máximo. Clique em “Copiar script para obter dados”, abra o Console (F12), cole e pressione Enter. O script baixa um CSV e copia os dados em formato de planilha.
A diferença será calculada como Estoque máximo − Estoque atual. Se o resultado for negativo, será apresentado como zero.
Etapa 2

2Gerar pedidos

Informe o produto e cole as lojas com a quantidade calculada na etapa anterior.

Aceita: 0214 | 3, 0214;3 ou 0214 [tab] 3.
Desative para preencher e conferir manualmente antes do envio.
Etapa 3

Script de criação de pedidos

Copie e execute no Console do Chrome, na tela do sistema.

Etapa 4 — último passo

4Script para aprovação

Gera um script que localiza todos os botões “Aprovar” disponíveis na tela, aprova um por vez e confirma em “Salvar”.

Atenção: a aprovação pode liberar pedidos de forma definitiva. Confira a lista na tela antes de executar. O script pedirá confirmação, processará os pedidos sequencialmente e interromperá se não localizar o botão “Salvar” ou se o modal não fechar.
Ferramenta local. Os dados preenchidos nesta página não são enviados para nenhum servidor.
